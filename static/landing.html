The problem

Same station, same lead time, three different answers.

A forecaster is left to pick one — usually by habit — with no record of which model has actually been right lately, and no attached confidence. A model's skill shifts with lead time, regime, and ensemble spread, so a fixed weight is wrong as often as it's right.

How it works

An adaptive weight engine, not a fixed average.

For every forecast, an XGBoost weight model scores each input's reliability against lead time, ensemble spread, humidity, temperature, wind, and regime — then a softmax layer turns those scores into three weights that always sum to one.

Weights that move

Recomputed per station, per lead time, per run — not fixed at deployment.

02

Calibrated uncertainty

Conformal prediction gives every forecast an 80% interval, not just a point value.

03

Zero target leakage

Reference rainfall is used only to build training targets and score results — never as an input feature.

Geospatially aware

Every forecast is tied to a real station and grid cell across the Indian meteorological network.
